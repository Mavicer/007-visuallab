# 终端状态面板

更新于 2026-10-16。原启动命令会默认开启终端状态面板。图像预览已合并为单个窗口：左侧彩色结果、右上灰度、右下二值；左上角另显示简要模型/设备/速度/资源信息。无需改用另一套识别流程。`--terminal off` 不启用资源采样，因此图像中的 CPU/GPU 显示 N/A，循环 FPS 仍可显示。

## 运行

```bash
cd ~/Desktop/GitHub/AI_Studio/Projects/007_VisualLab
uv sync --extra ocr --extra yolo

# 当前文字定位候选；终端面板默认启用
uv run --extra ocr --extra yolo python -m visuallab --backend text --text-locator yolo --weights models/text-pilot-v1.pt --yolo-size 640 --full-frame-text

# 原有 card 混合命令也自动启用面板
uv run --extra ocr --extra yolo python -m visuallab --backend hybrid --weights models/card-pilot-v1.pt --yolo-size 416
```

可选参数：

| 参数 | 用途 |
|---|---|
| `--terminal auto` | 默认。普通终端独立页面刷新，退出恢复原终端与光标；管道或窄终端自动采用文本日志 |
| `--terminal log` | 一次完整模型/状态信息，后续输出限频文本快照，适合保存日志 |
| `--terminal off` | 关闭面板及资源采样，保存原始帧等事件仍可见 |
| `--status-interval 1` | 每秒刷新一次界面；默认 .5 秒，最小 .2 秒；资源采样约每秒一次 |

离线 `--image` 默认输出静态文本面板，随后正常保存图片和 JSON。离线单帧没有视频 FPS，CPU 尚未完成采样时显示 N/A。

按键仍由图像窗口接收：图像窗口在前台时按 **S** 保存原始帧，按 **Q/Esc** 退出；在终端按 **Ctrl+C** 也会执行清理。终端本轮没有加入跨帧目标选择或 ID。

## 显示内容

- **当前配置**：检测后端、范围或 ROI、模型文件名、推理框架与 CPU/MPS 设备、YOLO 输入尺寸。YOLO 使用 MPS 时，现有 ONNX OCR 仍单独显示 CPU。
- **速度**：画面尺寸、已处理帧数、近期实际处理循环 FPS、检测/读取调用总耗时；已有诊断的路径另显示对象定位、文字定位和 OCR 耗时。FPS 包含取帧、处理、显示和等待；不是相机标称 FPS，也不是 `1000/推理耗时`。
- **识别**：本帧候选数量、接受/未知数量、文本、分数、上游定位分数、中心和 xywh 框。真问号显示为 `OK "?"`，拒识显示 `UNKNOWN 未知`。行号不是追踪 ID，上一帧内容不会在空帧中伪装为当前结果。
- **CPU**：全机百分比，以及本进程百分比。进程单核满载为 100%，多核运行可以超过 100%。
- **内存**：本进程 RSS；全机 `total-available` 与总内存。
- **GPU**：Apple 驱动通过只读 IORegistry 公开的全机设备活动快照。它不是本进程 GPU 百分比；其他程序也可能贡献该值。读取失败或系统不提供时显示 N/A，正常取得的 0% 会显示 0%。
- **MPS 张量内存**：仅在 PyTorch 已载入且 MPS 可用时读取当前分配量；不是独立显存总量。M2 使用统一内存，不能简单把此项与 RSS 相加。

文字表最多展开 8 行，并按终端高度缩减；长文本截断显示，其完整单帧结果可通过现有离线 JSON 检查。小于约 60 列/20 行时使用普通日志，避免页面错位。

## 实现与成本

`visuallab/terminal_status.py` 独立负责资源采样与界面；`camera.py` 只提交当前帧结果，`__main__.py` 提供真实启用的模型配置。后台仅一个采样线程；GPU 查询有 .4 秒超时，不阻塞推理循环；退出时停止线程并恢复终端。没有为监控载入额外深度学习框架，也不需要管理员权限。

基础依赖新增 `psutil>=7.2,<8`，锁定本机已有 7.2.2；已离线同步。CPU 首次采样缺少有效间隔，显示 N/A。macOS 在本次环境中拒绝 IORegistry archive 格式，因此使用可工作的只读文本格式并精确解析设备活动字段；不同系统仍可能没有该字段。

## 验收

1. 重启原命令，确认模型文件、后端与设备和启动参数一致。
2. 展示字符或短文本，检查终端文本和图像标签一致；移走后本帧结果应清空。
3. 等待约两秒，检查 CPU/内存更新。GPU 字段可能为有效的 0% 或 N/A，不能据此把 CPU 模型误判为 GPU 推理。
4. 比较 `--terminal log`、`--terminal off`；正常退出和 Ctrl+C 后终端光标应恢复。

42 项离线测试通过；已用本地真实文字模型和重复原始帧验证日志与 TTY 刷新、资源读取与线程退出。该演示没有访问摄像头，示例 FPS 不是摄像头实测结果。识别模型、训练权重和识别策略未改动。
