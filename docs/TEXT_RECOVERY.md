# 倾斜、透视与方向恢复

2026-10-16。本轮是输入链路优化，未训练或替换模型。`run visuallab` 默认打开；底层 Python CLI 仍默认 `--text-recovery off`，可明确开启。

```bash
run visuallab
run visuallab --text-recovery off  # 同权重对照
```

已运行的进程需退出后重新启动。终端范围栏会显示“姿态恢复 auto”，分阶段耗时包含恢复分支；恢复成功的结果标记 `RECOVERED`。离线 JSON 的每个 `inputs` 记录包含 `proposal_origin` 和 `recovery`：原始读数、尝试方向、结果、分数及拒绝原因。`ocr_inputs/` 保存真正用于读取的灰度/二值输入；成功恢复时另保存原始灰度裁剪。

## 原因与实现

当前快捷命令使用 YOLO 单类 `text` 水平框。它提供文字范围，不能提供阅读方向或真实纸角；这条路线此前没有使用纸片透视校正。OCR 是文本行读取器，输入仍歪斜时会失败。

1. 已接受的灰度结果优先保留。只有原结果未知才尝试恢复，不根据二值诊断分数覆盖输出。
2. 在失败文字附近寻找可见、完整的浅色平面四角，局部搜索最长边不超过 480。四角不足、被裁剪或区域不相符就跳过；检测矩形不能冒充纸角。只有观测四角支持的单应矩阵才用于透视变换。
3. 备选前景路径保留内部暗色连通分量的原始灰度值与分离标点，去掉连到裁剪边界的可疑背景。用墨迹最小外接矩形生成一个小角度修正，再检查两个四分之一转向；不使用字符白名单、数字笔画规则或新模板。
4. 恢复候选分数需至少 .85（或更严格的读取阈值），与不同文字的竞争候选分差至少 .15；邻近 ±7° 的两次检查需有一次一致且分数至少 .75，出现另一种高分文字则拒绝。这些是保守启发式，未做概率校准，不能保证方向正确。
5. 每帧最多恢复两处；每处最多 6 次恢复 OCR，成功后另做一次二值诊断。完全无文字框时只补一次 90° YOLO 检测，提案映回原图后读取，避免把横线强制读成旋转的 `1`。仍有一个框时不为漏掉的第二张卡增加全图扫描。
6. 裁剪、旋转、单应矩阵与画面平移分别保留逆变换，二值墨迹按完整变换链投回原图。原始 S 保存、检测接口、目标坐标和将来的控制回调继续使用摄像头坐标。

`text_recovery.py` 独立于具体字符和 YOLO 类别。真实平面四角、墨迹旋转与识别门槛分开；未来角点/分割模型可替换几何来源。浅色纸面几何是可选辅助，不是其他载体进入 OCR 的必要条件。

## 证据及限制

- 新批次 38 张，31 张纳入人工字符清单检查，共 39 个目标，匹配数量从 18 增至 22。4 张近侧立/弯曲且单帧内容不可靠的图单列；另外 3 张横线因不能确认是 `-` 还是旋转的 `1`，不计入语义准确率。这里是全帧字符数量匹配，非定位 IoU、跨帧身份或独立测试集准确率。
- 四张倾斜 `2/7` 新增正确输出。另三张可见横线从漏检恢复为输出 `-`，只计字形检出，若用户本意是“旋转的 1”则不能算读对。双卡与模拟标记仍有明显失败。此次 38 张中的成功恢复均非纸角单应矩阵，因此不能据此宣称真实空间透视已稳定解决。
- 旧 83 张回归：旧可读目标仍为 26/33，其他旧分组未退化；12 张已有无目标帧没有新增接受输出。这些负样本来自训练或邻近帧，不代表独立新场景误报率。
- 24 个字母、数字、问号、短文本合成输入检查从 18 到 21；使用已知文字 ROI，仅检查输入恢复，不衡量 YOLO 检测或摄像头准确率。
- 几何与运行预算单元测试覆盖真实四角、完整纸角检出/裁剪拒绝、无剪切旋转、反向坐标、分离标点、方向冲突拒绝、已接受结果不改动和预算上限。测试不代替模型能力验收。
- 原有高分误读仍保留；`3/m`、`6/9`、`1/-` 存在旋转歧义。弯曲纸片不是单一平面，近侧立、反光、遮挡及运动模糊也不能靠四点变换恢复丢失信息。
- 恢复分支增加 CPU 延迟；实时帧率需在摄像头环境确认。关闭开关可比较收益和耗时，无需换模型。

完整帧清单、比较图、JSON、耗时和本阶段报告在聊天输出 `VisualLab-倾斜与透视优化/`。以上是输入恢复阶段的冻结记录；后续用户授权的定位器训练已完成，最新标注、训练与默认模型决定见 [倾斜训练结果](TILT_TRAINING.md)。

## 下一轮模型工作

先按失败阶段整理数据：文字漏检需补文字框与旋转/透视增强；框正确但文字未知需保留 OCR 输入定位问题；需要真实平面校正时标注可见四角，遮挡角点标为不可见。普通 AABB 增加训练轮数不会产生角点，OBB 的旋转矩形也不等于投影四边形。

按连续拍摄片段/场景分组并去重；补同场景无目标帧，保留完整独立拍摄段作验收。继续维持单类文字定位和通用 OCR，不逐字增加 YOLO 类别；一次受限试验后比较旧数据、倾斜留出集和负样本，不自动替换当前权重。
